# CYSR Website

Council of Young Researchers (CYSR) landing page with a featured research section, interactive fluid stream calculator, and submission form.

## Local preview

Open `index.html` directly in a browser, or serve the folder with a simple local web server.

## Deploy to GitHub Pages

1. In the repository settings, go to Pages.
2. Set the source to the `main` branch and root folder `/`.
3. Your site will be published at a GitHub Pages URL.
